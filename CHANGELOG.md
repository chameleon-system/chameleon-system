# Changelog

## 8.0.0

### Changed

- Upgraded Chameleon System to version 8.0.
- Updated application configuration and routing for the current Symfony stack, including security and logout routes.
- Updated the set of bundled modules, including security, CMS backend, OAuth2, two-factor authentication, dashboard, image editing, Markdown CMS and e-commerce statistics.
- Updated the development toolset, including the Symfony Web Profiler.

### Added

- Added an up-to-date shop database dump for setup and testing.
- Added public project metadata describing the platform, supported languages, licensing and support information.
- Added contribution and security policies.

### Documentation

- Updated installation, contribution, issue-reporting and security-reporting guidance.
- Refreshed project branding and logo assets.

### Upgrade notes

- This is a major release. Review custom integrations, Composer dependencies, security routes and enabled modules before upgrading.
